# The cumulative prototype diverges from mattpocock's `/prototype`

mattpocock's rule is one throwaway prototype per question, committed to a `prototype/<name>` branch out of main. Devio composes screens, where coherence between pieces is what gets judged, so the prototype is one real HTML folder that grows across tickets, versioned in the effort and removed when the effort closes. `/prototype` stays valid for logic and state questions; it is never run on a composition ticket.
